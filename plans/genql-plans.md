# Genql Plans

Genql is an open-source MIT-licensed project available freely on GitHub and npm. There are no commercial subscription tiers or paid plans for the core code generation library. The tool is free to use for any purpose.

## Open Source (Free)

- **Cost:** Free
- **License:** MIT
- **Source:** https://github.com/remorses/genql
- **npm Package:** @genql/cli

### Included Features

- Full TypeScript client generation from any GraphQL schema
- IDE auto-completion and type validation
- Zero runtime dependencies (no graphql package required)
- Batched query support
- Subscription support
- Works in browser, Node.js, Deno, Cloudflare Workers, and Bun
- `__scalar: true` to fetch all scalar fields
- Query migration converter tool at https://genql.dev/converter
- Community support via GitHub Issues

## Notes

Because Genql generates a client library that you run against your own GraphQL endpoints, there are no API usage quotas, rate limits, or metered costs imposed by Genql itself. Any runtime costs depend on the GraphQL service the generated client connects to.

For details see the GitHub repository: https://github.com/remorses/genql
